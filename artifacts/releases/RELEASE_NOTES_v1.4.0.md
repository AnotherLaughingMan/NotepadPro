# Notepad Pro v1.4.0

## Version 1.4.0 - August 11, 2026

### Bug Fixes

- Fixed New Tab and Open File flows replacing existing saved or unsaved tabs.
- Opening a file now preserves an existing untitled document.
- Fixed the first untitled tab being incorrectly named `Untitled (1)`.
- Fixed Markdown Rendered mode losing content when switching documents quickly.
- Cancelled stale rendered Markdown updates before new document content is applied.

- Installer (InstallMe.Lite): `NotepadPro-v1.4.0-20260811-234428.exe`
- App package (framework-dependent, win-x64): `NotepadPro-v1.4.0-20260811-234428.zip`
